LOAFS CASINO — White, blue and pink solo edition

This update makes Blackjack, Baccarat and Roulette playable without another player.
It replaces the incomplete multiplayer prototype with a reliable solo game version.
Game points are scorekeeping only; they cannot be purchased, wagered, transferred,
or exchanged for money or prizes.

To update GitHub:
1. Extract this ZIP.
2. In your GitHub repository open the loafs_casino folder.
3. Replace package.json, server.js, and public/index.html with the matching files.
4. Commit the changes to main.
5. Render should automatically deploy. If not, use Manual Deploy > Deploy latest commit.

Keep the folder structure. Do not upload the ZIP itself as a replacement.
This version is solo only; online accounts, shared tables, and live multiplayer are not included.
